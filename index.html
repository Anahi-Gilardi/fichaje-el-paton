⚙️ Configurar conexión con Google Sheets

Pegá la URL de tu implementación de Google Apps Script (debe terminar en /exec). Si la dejás vacía, el sistema funcionará en Modo Local de prueba en este navegador.

🔑 Cambiar PIN de empleado

Ingresá el nuevo PIN numérico (4 a 8 dígitos).

🛑 Forzar egreso de turno abierto

Si el empleado se olvidó de marcar la salida, podés cerrarle el turno indicando la hora de salida (o dejarla vacía para usar la hora actual).

Dejá este campo en blanco si querés registrar la salida con la hora actual de Córdoba.
🗑️ Eliminar usuario

¿Estás seguro de que querés eliminar este usuario de la nómina?

⏱️ Configurar jornada diaria

Definí la cantidad de horas de la jornada diaria normal de este empleado (por defecto 8 h). Todo lo que supere esta jornada en un mismo día se registrará como hora extra.
